Deck cards

One card per deck, the size of a Magic card (2.5 × 3.5 in), so you can print it and sleeve it with the deck. The QR code opens the deck on Archidekt. The bracket is the one you set on Archidekt. Click a card to leave it out of the printout. In the print dialog, turn on background graphics and print at 100% scale.

To leave something out: click a color, type or deck twice, or start a word with a minus sign. For example, "-sol" in the name box, "Elf -Druid" for subtypes, or "-SLD" for sets.

Deck overlap

How many cards each pair of decks shares, not counting basic lands. Select a number to list those cards.

Sets lists the printings you play, with copy counts when there's more than one. Typing set codes in the Sets box (separated by commas or spaces) limits everything, copies, decks and prices included, to cards from those sets. A partial code matches every set starting with it, so "MH" covers MH1, MH2 and MH3. Price is per copy, from the store chosen in "Prices from". If you play more than one printing of a card, it shows the cheapest. Bold decks run the card as a commander; dashed ones run it as a proxy.
